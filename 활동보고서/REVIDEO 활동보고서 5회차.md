1. 일정별 주요 활동

가. 개발 장비 검토
1) 개발 장비 구성 검토
가) 아날로그 영상 디지털 변환에 필요한 장비 구성과 사양을 검토함
나) 이전에 구매한 IEEE 1394 확장 카드를 활용한 영상 캡처 환경을 검토함
다) 영상 보정 및 편집 작업에 필요한 하드웨어와 소프트웨어 요구 사양을 정리함
라) 향후 영상 캡처 테스트에 필요한 추가 장비와 준비 사항을 확인함

나. 키링 및 NFC 설명 구체화
1) 서비스 동작 방식 정리
가) NFC 키링 샘플의 구조와 스마트폰 태깅 동작 과정을 단계별로 정리함
나) 태깅 시 영상 및 콘텐츠 페이지로 연결되는 흐름을 구체적으로 설명할 수 있도록 정리함
다) 키링 제작부터 NFC 태그 등록, 콘텐츠 연동까지의 제작 공정을 정리함
라) 멘토링 및 발표 자료에 활용할 수 있도록 서비스 설명을 문서화함

다. 디지털 추억 페이지 웹사이트 구성
1) 웹사이트 구성 설계
가) 디지털 추억 페이지의 화면 구성과 콘텐츠 배치를 설계함
나) 대표 영상, 사진 갤러리, 추억 메시지, 타임라인 등의 섹션 구성을 정리함
다) 모바일 환경에서 세로로 스크롤하며 감상할 수 있는 페이지 구조를 구성함
라) NFC 태그에는 영상 파일이 아닌 페이지 주소를 등록하는 구조를 검토함

라. 개발 도구 검토 및 설치·활용 테스트
1) 개발 도구 검토
가) 웹 페이지 제작과 영상 작업에 활용할 개발 도구를 조사하고 검토함
나) 선정한 도구를 설치하고 기본 기능을 확인함
다) 간단한 제작 실습을 통해 도구의 활용도를 테스트함
라) 디지털 추억 페이지 구현에 적합한 개발 환경과 도구 활용 방안을 정리함

마. 느낀점 및 향후 계획
이번 활동에서는 아날로그 영상 변환에 필요한 개발 장비를 검토하고, NFC 키링과 영상 연동 동작 과정을 구체적으로 정리하면서 서비스 설명을 명확히 할 수 있었다. 또한 디지털 추억 페이지의 웹사이트 구성을 설계하고 개발 도구를 설치·활용해 보며 본격적인 개발 준비를 진행하였다. 이를 통해 키링 샘플과 디지털 페이지를 연결하는 서비스의 전체 구조를 구체화할 수 있었다. 향후에는 디지털 추억 페이지를 제작하고 NFC 태그와 연동하여 스마트폰 태깅으로 페이지에 접근하는 기능을 검증하며, 영상 캡처 환경 구축을 위한 장비 준비를 이어 나갈 계획이다.
