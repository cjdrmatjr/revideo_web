# RE:VIDEO — 디지털 추억 페이지

NFC 키링을 스마트폰에 태그하면 열리는, 모바일 청첩장 형식의 디지털 추억 페이지입니다.
영상·사진·추억 메시지·복원 전후 비교를 세로 스크롤 한 페이지에 담았습니다.

> 현재 모든 콘텐츠는 **샘플(테스트용)** 이며, 이미지 자리는 실제 사진을 넣기 전까지 비어 있습니다.

## 주요 기능

- 대표 영상 재생 (재생 버튼 + 다운로드 버튼)
- 사진 갤러리 (탭 시 확대 라이트박스, 좌우 이동)
- 복원 전/후 비교 슬라이더 (드래그·키보드 조절)
- 추억 타임라인
- 공유 / 링크 복사
- 모바일·PC 반응형, 스크롤 등장 애니메이션, 접근성(`prefers-reduced-motion`, 키보드 포커스) 대응

## 구조

```
memory-page/
├── index.html        # 페이지 본문 (콘텐츠 교체는 여기)
├── css/style.css     # 스타일 (밝은 톤, 반응형)
├── js/main.js        # 상호작용 (재생·슬라이더·라이트박스·공유)
└── assets/
    ├── sample-video.mp4     # 샘플 영상 (실제 영상으로 교체)
    ├── sample-hero.svg      # 표지 자리 (현재 빈 파일)
    ├── sample-1~4.svg       # 갤러리 자리 (현재 빈 파일)
    └── sample-restore.svg   # 복원 비교 자리 (현재 빈 파일)
```

의존성 없음 — vanilla HTML/CSS/JS. 빌드 과정도 없습니다.

## 실행 방법

```bash
cd memory-page
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000/` 접속. (파일을 직접 더블클릭해도 동작합니다)

## NFC 연동

NFC 태그(Tools 등)에 **영상 파일이 아니라 이 페이지의 URL**을 등록하면 태깅 시 페이지가 열립니다.

```
https://<배포 주소>/memory-page/
```

배포 예시: GitHub Pages, Netlify, Vercel 등 정적 호스팅 어디든 가능합니다.

## 콘텐츠 교체 방법

`index.html`에서 `<!-- [교체] -->` 주석을 검색하면 바꿀 위치가 나옵니다.

| 교체할 것 | 위치 |
|---|---|
| 제목·날짜 | `index.html` 히어로 부분 (`hero__title`, `hero__date`) |
| 추억 메시지 | `index.html` 메시지 섹션 |
| 영상 파일 (재생) | `index.html` ~70번 줄 `src="assets/sample-video.mp4"` |
| 영상 파일 (다운로드 링크) | `index.html` ~88번 줄 `href="assets/sample-video.mp4"` |
| 저장 파일명 | `index.html` ~88번 줄 `download="..."` |
| 사진 | `assets/sample-1~4.svg` 자리에 실제 사진(jpg 등)을 넣고 `index.html` 갤러리의 경로를 수정 |
| 복원 비교 이미지 | `assets/sample-restore.svg` 자리 + `index.html` 비교 섹션 |
| 타임라인 | `index.html` 타임라인 섹션 |

라인 번호는 편집하면 이동할 수 있으니 `<!-- [교체] -->` 검색을 우선 사용하세요.

## 유의사항

- 복원 전/후 비교는 동일 이미지에 필터를 적용한 **기능 데모**이며, 실제 영상 복원 결과가 아닙니다.
- 다운로드 버튼은 현재 누구나 저장할 수 있는 열린 링크입니다. 비공개·권한 관리는 별도 설계가 필요합니다.
- 사진·영상 등 실제 가족 콘텐츠를 넣을 때는 초상권·저작권·개인정보 범위를 확인하세요.
